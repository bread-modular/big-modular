# drive panels (6HP)

| Directory | Contents |
|---|---|
| `front-pcb/` | Native passive FR4 panel `drive-panel.kicad_{pro,pcb}`: 30.0 x 128.5 x 1.6 mm, NPTH only, F.SilkS labels. Generated by `../tools/build_layout.py` from `../docs/geometry.json` |
| `front-cad/` | FreeCAD printable panel, 2.0 mm thick, plain (no labels): `build_front_panel.py`, `.FCStd`, `.step`, `.stl` |

Holes: jacks Ø6.2, pots Ø7.2, rail holes Ø3.2 (X12.58, as modules/hats). The panel mounts on
the jack bushings with the PJ301M-12 nuts plus the rail screws; the RV09 pots take no nut.
The printed panel has the same holes.

Regenerate the printed panel headless from `modules/drive`:

```sh
~/Applications/FreeCAD_1.1.3.AppImage freecadcmd panels/front-cad/build_front_panel.py
```

The script reads the outline and holes from `front-pcb/drive-panel.kicad_pcb` and asserts them
against `docs/geometry.json`; it checks a single valid solid, the drilled-blank volume and a
closed manifold STL. Print suggestion: PETG/ABS, front face down, 0.2 mm layers. Holes are
nominal: ream after printing. The PJ301M-12 threads leave ~0.5 mm past a 2.0 mm nut. Not test-printed; no physical-fit claim.
