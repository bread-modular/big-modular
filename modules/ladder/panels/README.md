# ladder panels (6HP)

| Directory | Contents |
|---|---|
| `front-pcb/` | Native passive FR4 panel `ladder-panel.kicad_{pro,pcb}`: 30.0 x 128.5 x 1.6 mm, NPTH only, F.SilkS labels. Generated by `../tools/build_layout.py` from `../docs/geometry.json` |
| `front-cad/` | FreeCAD printable panel, 2.0 mm thick, plain (no labels): `build_front_panel.py`, `.FCStd`, `.step`, `.stl` |

The two panels are alternatives with the same 11 holes (4 jacks Ø6.2, 3 pots Ø7.2, 2 CV LEDs
Ø3.2, 2 rail holes Ø3.2). Either one mounts on the jack bushings with the PJ301M-12 nuts plus the rail
screws; the RV09 pots take no nut. Regenerate the printed panel headless from `modules/ladder`:

```sh
freecadcmd panels/front-cad/build_front_panel.py
```

The script reads the outline and holes from `front-pcb/ladder-panel.kicad_pcb` and
asserts them against `docs/geometry.json` (as `modules/midi`). It checks for a single
valid solid, the drilled-blank volume (plain, no engraving) and a closed manifold STL.
Print suggestion: PETG/ABS, front face down, 0.2 mm layers. Holes are nominal: ream
after printing. The PJ301M-12 threads leave ~0.5 mm past a 2.0 mm nut on the 2.0 mm
print; the LED domes sit 0.4 mm behind its front. Not test-printed; no physical-fit claim.
