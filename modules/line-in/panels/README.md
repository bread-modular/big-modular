# line-in panels (4HP)

| Directory | Contents |
|---|---|
| `front-pcb/` | Native passive FR4 panel `line-in-panel.kicad_{pro,pcb}`: 20.0 x 128.5 x 1.6 mm, NPTH only, F.SilkS labels. Generated by `../tools/build_layout.py` from `../docs/geometry.json` |
| `front-cad/` | FreeCAD printable panel, 2.0 mm, plain: `build_front_panel.py`, `.FCStd`, `.step`, `.stl` |

Holes: jacks Ø6.2, pots Ø7.2, rail holes Ø3.2 at X12.58 (as audio-out). The panel
hangs on the four jack nuts; the RV09 pots take no nut. Regenerate the print from
`modules/line-in`:

```sh
~/Applications/FreeCAD_1.1.3.AppImage freecadcmd panels/front-cad/build_front_panel.py
```

The script reads the outline and holes from the panel PCB and asserts them against
`docs/geometry.json`. Not test-printed; no physical-fit claim.
