# midi panels (4HP)

| Directory | Contents |
|---|---|
| `front-pcb/` | Native passive FR4 panel `midi-panel.kicad_{pro,pcb}`: 20.0 x 128.5 x 1.6 mm, NPTH only, F.SilkS labels. Generated by `../tools/build_layout.py` from `../docs/geometry.json` |
| `front-cad/` | FreeCAD printable panel, 2.0 mm thick, labels engraved 0.4 mm: `build_front_panel.py`, `.FCStd`, `.step`, `.stl` |

The two panels are alternatives with the same holes. Either one mounts on the
jack bushings with the PJ301M-12/PJ366ST nuts, plus the two rail screws. No
brackets are used. Regenerate the printed panel headless from `modules/midi`:

```sh
~/Applications/FreeCAD_1.1.3.AppImage freecadcmd panels/front-cad/build_front_panel.py
```

The script reads the outline, NPTH holes and labels from
`front-pcb/midi-panel.kicad_pcb` and asserts them against `docs/geometry.json`.
It checks for a single valid solid, the drilled-blank volume, a non-zero
engraving and a closed manifold STL. Print suggestion: PETG/ABS, front face
down, 100% infill or 4+ perimeters, 0.2 mm layers. Holes are nominal (Ø6.2 jack,
Ø3.2 LED/rail): ream after printing. The geometry is nominal only; no
physical-fit or strength claim.
