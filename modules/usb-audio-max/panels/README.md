# usb-audio-max panels (10HP)

| Directory | Contents |
|---|---|
| `front-pcb/` | Native passive FR4 panel `usb-audio-max-panel.kicad_{pro,pcb}`: 50.5 x 128.5 x 1.6 mm, NPTH only, F.SilkS labels. Generated by `../tools/build_layout.py` from `../docs/geometry.json` |
| `front-cad/` | FreeCAD printable panel, 2.0 mm thick, plain (no labels): `build_front_panel.py`, `.FCStd`, `.step`, `.stl` |

Holes: 14 jacks Ø6.2 (three columns X7.0 / 25.25 / 43.5, rows Y46.3 / 62.25 / 78.2 / 94.15 / 110.1;
IN 1-6 in the top two rows, OUT 1-8 below, the ninth spot empty), USB-C slot 9.5 x 3.7 mm at X25.25
Y16 (the shell stands 1.3 mm proud), rail holes Ø3.2 at X12.58 / X43.06, standoff holes H20/H21 Ø3.2 at X5.0 / X45.5 Y13.75 (top corners, level with the USB-C) (coaxial with the
carrier MS1/MS2 M3x10 hex standoffs, `mount_standoffs`). It mounts on the jack
bushings with the PJ301M-12 nuts plus the rail screws; two M3x6 screws from the front into the standoffs. The printed panel has the same holes and slot; the USB-C shell stands 0.9 mm proud of it.

Regenerate the printed panel headless from `modules/usb-audio-max`:

```sh
~/Applications/FreeCAD_1.1.3.AppImage freecadcmd panels/front-cad/build_front_panel.py
```

The script reads the outline and holes from `front-pcb/usb-audio-max-panel.kicad_pcb` and asserts them
against `docs/geometry.json`; it checks a single valid solid, the drilled-blank volume and a
closed manifold STL. Print suggestion: PETG/ABS, front face down, 0.2 mm layers. Holes are
nominal: ream after printing. The M3x6 screws still reach 4.0 mm into the standoffs. Not test-printed; no physical-fit claim.
