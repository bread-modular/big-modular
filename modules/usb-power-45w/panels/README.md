# usb-power-45w panels and brackets (4HP)

| Directory | Contents |
|---|---|
| `front-pcb/` | Native passive FR4 front panel `usb-power-45w-panel.kicad_{pro,pcb}`, 1.6 mm |
| `front-cad/` | FreeCAD 3D-print front panel, 1.6 mm, no labels: `build_front_panel.py`, `.FCStd`, `.step`, `.stl` (details in `front-cad/README.md`) |
| `bracket/` | FreeCAD 3D-print panel-to-carrier bracket (print two): `build_bracket.py`, `.FCStd`, `.step`, `.stl` |

The PCB panel and the printed panel are alternatives; both mount with the same two printed brackets.
